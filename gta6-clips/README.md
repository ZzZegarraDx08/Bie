# gta6-clips

Material sobre un canal de clips de GTA 6 operado por agentes, analizado y unificado.

- [ANALISIS.md](ANALISIS.md): qué dicen las 3 fuentes, el pipeline común, las contradicciones, los riesgos y los datos que faltan
- [PROMPT_MAESTRO.md](PROMPT_MAESTRO.md): el prompt unificado, listo para rellenar
- [RULES.md](RULES.md) / [STATUS.md](STATUS.md): la memoria persistente del agente
- [config.example.yaml](config.example.yaml), [permissions.csv](permissions.csv): configuración y lista blanca de streamers
